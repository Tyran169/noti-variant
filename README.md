# Notification Variants with Shadcn

This project is a Next.js application showcasing various notification styles and UI components built with Shadcn. It includes demos for alerts, buttons, and custom toast notifications.

## Features

- **UI Components**: Pre-built components like `Alert`, `Button`, and `Sonner` with multiple variants.
- **Notification Demos**: Interactive pages demonstrating the usage of these components.
- **Utility Functions**: Includes `hashIdString` for generating unique IDs.
- **Customizations**: Breaking changes from standard Next.js conventions.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Tyran169/noti-variant.git

   cd noti-variant
   ```

2. Install dependencies:

   ```bash
   pnpm install
   ```

3. Run the development server:

   ```bash
   pnpm dev
   ```

## Project Structure

- `src/components`: Contains reusable UI components.
- `src/pages`: Includes demo pages for the components.
- `src/lib`: Utility functions like `hashIdString`.
- `styles`: CSS files for styling.
